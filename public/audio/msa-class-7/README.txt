Audio files for MSA Beginners Course - Class 7

Audio File Naming Convention:
- Questions: q1.mp3, q2.mp3, q3.mp3, ..., q120.mp3
- Answers: a1.mp3, a2.mp3, a3.mp3, ..., a120.mp3

Place your .mp3 audio files in this directory (/public/audio/msa-class-7/).
They will be automatically served by Vite at the URLs:
- /audio/msa-class-7/q1.mp3
- /audio/msa-class-7/a1.mp3
etc.

You can also edit or customize paths in /src/data/msaClass7Data.ts.
